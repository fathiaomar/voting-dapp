# Contributing to Voting DApp

Thank you for your interest in contributing to the Voting DApp project! Contributions and pull requests are welcome.

## How to Contribute

1. **Fork the Repository:** Create your own copy of the repository.
2. **Create a Feature Branch:** `git checkout -b feature/your-feature-name`
3. **Make Your Changes:** Implement your feature or fix.
4. **Run Tests & Linting:** Ensure your code passes all lint checks (`yarn next:lint`).
5. **Commit & Push:** Commit your changes with clear messages and push to your fork.
6. **Open a Pull Request:** Submit a PR targeting the `main` branch with a description of your changes.

## Guidelines

- Keep code clean, formatted, and documented.
- Make sure existing functionality remains intact.
