# 🗳️ Voting DApp

A decentralized governance and voting application built on top of Ethereum using Scaffold-ETH 2, Next.js, and Hardhat.

## 🚀 Features

- **On-Chain Voting:** Submit proposals and cast votes directly on the blockchain via smart contracts.
- **Real-Time Governance:** Live proposal tracking, active vote counters, and DAO balance monitoring.
- **Web3 Wallet Support:** Connect using RainbowKit with local burner wallets or injected Web3 wallets (e.g., MetaMask).
- **Custom Branding:** Clean, responsive UI powered by DaisyUI and Tailwind CSS.

## 🛠️ Tech Stack

- **Smart Contracts:** Solidity, Hardhat
- **Frontend:** Next.js, React, Tailwind CSS, DaisyUI
- **Web3 Integration:** Wagmi, Viem, RainbowKit
